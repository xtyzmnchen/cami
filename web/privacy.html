隐私政策

我们重视孩子与家庭的隐私。本政策说明「小皇冠」如何收集、使用与保护信息。使用本应用即表示你已阅读并理解本政策。

Privacy Policy

Updated: 2026-11-16 · Applies to Cami (iOS / Android / Web)

We respect family privacy. This policy explains how Cami collects, uses, and protects information. By using the app, you acknowledge this policy.

1. 我们是谁

「小皇冠」（包名 / Bundle：com.cami.day.cami）是面向家庭的每日打卡、积分、诗词与小游戏工具，可由家长与孩子共同使用。

1. Who we are

Cami (package / bundle: com.cami.day.cami) is a family daily check-in, points, poems, and mini-games app for parents and children.

2. 我们收集哪些信息

  • 账号信息：手机号、密码（本地哈希存储于你的同步电脑）、孩子昵称、年龄/年级等你填写的资料。
  • 打卡与学习数据：任务完成情况、积分、诗词/单词进度、游戏分数等。
  • 可选媒体：若你授权，可能使用麦克风（语音朗读/识别）、相册或相机（作业图片等）。
  • 设备与日志：为保障同步与排错，可能在本地或你自建的同步服务上保留必要运行日志；我们不出售这些数据。

本应用不以广告追踪为目的收集信息，也不强制要求关联第三方广告账号。

2. What we collect

  • Account: phone number, password (hashed on your sync PC), child nickname, age/grade, and other profile fields you enter.
  • Learning data: task completion, points, poem/vocab progress, game scores.
  • Optional media: with permission, microphone (TTS / speech) and photos/camera (e.g. homework images).
  • Device / logs: limited runtime logs for sync and troubleshooting on-device or on your own sync server. We do not sell this data.

Cami does not collect data for advertising tracking and does not require third-party ad accounts.

3. 信息如何存储与同步

  • 默认优先保存在本机（如 SharedPreferences / 本地文件）。
  • 若你配置了「同步地址」，数据会在你指定的家庭电脑同步服务（如通过 cpolar 暴露的自建服务）与手机之间同步。
  • 同步地址发现文件可能托管在 GitHub / GitHub Pages，仅包含同步服务 URL 与口令提示字段，不含孩子详细学习内容。
  • 我们不会把你的打卡内容上传到与家庭同步无关的商业云盘进行分析或出售。

3. Storage and sync

  • Data is primarily stored on device.
  • If you set a sync URL, data syncs between the phone and your own home PC sync server (e.g. via cpolar).
  • A public discovery file on GitHub / GitHub Pages may contain only the sync service URL and token hint—not detailed learning content.
  • We do not upload check-in content to unrelated commercial clouds for profiling or sale.

4. 权限说明

  • 网络：登录、同步、拉取最新同步地址。
  • 麦克风 / 语音识别：朗读、语音相关功能（需你授权）。
  • 相机 / 相册：作业或打卡配图（需你授权）。
  • 通知 / 闹钟：学习提醒（可在系统设置中关闭）。

你可以在系统设置中随时撤销授权；撤销后相关功能可能不可用，但不影响其他基础功能。

4. Permissions

  • Network: sign-in, sync, refresh sync endpoint.
  • Microphone / speech: reading aloud and speech features (with consent).
  • Camera / photos: homework or check-in images (with consent).
  • Notifications / alarms: study reminders (can be disabled in system settings).

You may revoke permissions anytime; some features may stop working, but core features remain.

5. 儿童隐私

本应用面向家庭场景，可能由未成年人在家长指导下使用。请家长保管好同步口令与手机号账号，不要将同步地址与口令发给无关第三方。我们不会故意向儿童展示行为广告。

5. Children’s privacy

Cami is built for families and may be used by children with parental guidance. Please keep sync tokens and account credentials private. We do not intentionally show behavioral ads to children.

6. 你的权利

  • 可在应用内修改资料、清理或重置本地数据（视功能入口而定）。
  • 可停止使用同步，或在同步电脑上删除 cami-data 数据目录。
  • 如需帮助，请通过「技术支持」页联系我们。

6. Your choices

  • Edit profile and clear/reset local data where the app provides those actions.
  • Disable sync, or delete the cami-data folder on your sync PC.
  • Contact us via the Support page for help.

7. 政策更新

我们可能更新本政策，并在本页面展示最新版本与日期。重大变更时，建议你重新阅读。

7. Changes

We may update this policy and post the latest version and date here. Please review again after material changes.
