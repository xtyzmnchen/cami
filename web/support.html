常见问题

  • 显示「还没连上同步电脑」：请确认家里电脑已运行同步服务与 cpolar，并在 App 中点击「刷新同步地址」，或手动填写最新公网地址与口令（默认 cami-home）。
  • 同步地址是旧的：公网隧道重启后地址会变。以 GitHub 上最新的 sync-endpoint.json 为准，或让电脑端重新发布地址。
  • 登录失败：检查手机号 11 位、密码至少 4 位；确认网络可访问同步地址。
  • 语音/相机不可用：到系统设置中为「小皇冠」开启麦克风、语音识别或相册权限。
  • 安装包：Android 可使用蒲公英分发页；iOS 需通过 Xcode / TestFlight 等合规方式安装。

FAQ

  • “Not connected to sync PC”: Make sure the home PC is running the sync server and cpolar, then tap “Refresh sync URL” in the app, or enter the latest public URL and token (default cami-home).
  • Stale sync URL: Tunnel URLs change after restart. Use the latest sync-endpoint.json on GitHub, or republish from the PC.
  • Sign-in fails: Use an 11-digit phone number and password (≥4 chars); ensure the sync URL is reachable.
  • Speech / camera unavailable: Enable microphone, speech recognition, or photos for Cami in system settings.
  • Install builds: Android via Pgyer distribution; iOS via Xcode / TestFlight or other compliant channels.
